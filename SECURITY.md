# Security Policy

## Reporting a vulnerability

Please do **not** report security issues in public issues or pull requests.

Use GitHub's private vulnerability reporting instead: open the **Security** tab
of this repository, select **Report a vulnerability**, and describe the issue.
This keeps the report private until a fix is available.

If private reporting is unavailable, open a minimal public issue asking for a
private channel — without including any vulnerability details.

## Supported versions

Development happens on `main`; fixes land there and are published as a new
tagged version. Please reproduce against the latest release before reporting.
